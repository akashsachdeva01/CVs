## Job Summary

### Position Overview
Inabia is seeking a highly skilled **Senior Network Test Engineer** to support advanced testing across **5G/LTE, Wi-Fi, and broadband/IP networking environments** for a leading telecommunications program based in London.

This role blends **wireless test engineering** with **enterprise and broadband networking validation**, requiring hands-on experience testing:
- Radio networks  
- IP connectivity  
- Customer-premises equipment (CPE)  

across both **laboratory and field environments**.

Engineers with strong **LTE/5G RAN or drive-testing backgrounds** along with **broadband/IP networking expertise** are strongly encouraged to apply.

---

## Required Skills & Experience

### Key Responsibilities

### Broadband & CPE / Gateway Validation
- Test residential and enterprise routers, gateways, modems, mesh Wi-Fi systems, and CPE devices  
- Validate performance, reliability, and stability across fiber, DSL, wireless broadband, and Ethernet backhaul  
- Execute LAN/WAN configuration workflows, device onboarding, and end-to-end connectivity validation  

### IP Networking, Routing & VPN Testing
- Configure and validate IPv4/IPv6, subnetting, VLANs, DHCP, DNS, NAT, port forwarding, and firewall rules  
- Test VPN technologies including:
  - IPsec  
  - SSL VPNs  
  - WireGuard  
  - OpenVPN  
- Troubleshoot Layer 2–Layer 7 connectivity using:
  - Wireshark  
  - tcpdump  
  - traceroute  
  - iPerf  

### Testbed Setup & Environment Ownership
- Build and maintain test environments combining routers, switches, servers, VPN endpoints, and test tools  
- Ensure test repeatability through:
  - Documentation  
  - Configuration management  
  - Version control  
- Integrate new firmware, OS builds, and network parameters into test cycles  

### Tools, Log Analysis & Reporting
- Use tools such as Wireshark, tcpdump, and iPerf  
- Perform deep log analysis including:
  - RRC  
  - NAS  
  - SIP  
  - RTP/RTCP  
  - System logs  
- Produce:
  - Test plans  
  - Defect reports  
  - KPI dashboards  
  - Root-cause analysis reports  
- Collaborate with:
  - Broadband engineers  
  - Device OEMs  
  - Network operators
