# IP Engineer – In-Building Wireless (IBW) Networks

## Position Summary

The IP Engineer will be responsible for the design, configuration, operation, and optimisation of IP networks that support in-building wireless solutions, specifically CommScope OneCell and Ericsson DOT System deployments.

This role will manage end-to-end IP connectivity between customer sites and the Cellnex data centre, ensuring secure, resilient, and high-performance transport for mobile traffic.

The engineer will collaborate closely with RF, integration, and operations teams to ensure seamless service delivery across multi-vendor environments.

---

## Key Responsibilities

### IP Network Design & Configuration

- Design and implement IP network architectures supporting CommScope OneCell and Ericsson DOT systems.
- Configure Layer 2 and Layer 3 services, including:
  - VLANs  
  - QoS  
  - Routing protocols  
  - Multicast  
  - VPNs
- Manage IP addressing schemes, DHCP, NAT, and subnetting across customer and core network interfaces.
- Develop and maintain:
  - Network diagrams  
  - HLD/LLD documentation  
  - Configuration templates
- Coordinate network readiness for:
  - New sites  
  - Expansions  
  - Technology upgrades  

---

### Network Operations & Maintenance

- Monitor network performance:
  - Availability  
  - Latency  
  - Throughput (customer-to-data-centre links)
- Troubleshoot and resolve:
  - Network faults  
  - Congestion issues  
  - Routing conflicts  
  - Transport bottlenecks
- Manage:
  - Firewall rules  
  - ACLs  
  - Security policies
- Support upgrades, software patches, and maintenance windows with minimal service disruption.
- Maintain:
  - Device inventory  
  - Configurations  
  - Network logs  

---
